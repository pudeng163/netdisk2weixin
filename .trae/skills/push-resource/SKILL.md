# Push Resource - 一键推送网盘资源（AI 挑选版）

用户说"帮我推送 N 个资源"、"转存 N 个 XX 类型的资源"、"推送资源不要短剧"时，**立即使用本 Skill**。

## 核心流程（固定四步）

```
① 检查/启动 PanSou  →  ② 空关键词拉取全量结果并导出清单
                           ↓
④ 用 --include 精准锁定推送  ←  ③ 【AI 逐条阅读清单，挑出符合要求的 N 个】
```

> **关键原则**：**每次推送都用空关键词**（`--kw` 不传，程序自动搜 `1`，即全网最新上传的全量结果）。
> **不再用主题关键词搜索**——单一关键词会高度同质化（搜"认知觉醒"全是同一本书的不同版本）。
> 改为「拉全量 → AI 阅读挑选」，才能得到多样化、且真正符合类型要求的资源。

---

## 1. 前置条件检查（必须先做）

### 步骤 1：检测 PanSou 盘搜服务是否在跑

```powershell
# RunCommand — blocking=true
try { (Invoke-WebRequest -Uri "http://localhost:8888/api/health" -UseBasicParsing -TimeoutSec 3).Content } catch { "NOT_RUNNING" }
```

- 返回 JSON 且 `status: "ok"` → 跳过步骤 2，进入第 2 节
- 返回 `"NOT_RUNNING"` 或报错 → 执行步骤 2

### 步骤 2：启动 PanSou（后台长驻）

```powershell
# RunCommand — blocking=false, command_type=web_server, wait_ms_before_async=4000
cd D:\网盘拉新项目\netdisk2weixin
powershell -ExecutionPolicy Bypass -File .\start_pansou.ps1
```

然后每 2 秒轮询一次 health 接口，最多等 60 秒直到返回 `{"status":"ok"}`。
超时则报错并终止，不要继续执行转存流程。

## 3. 【AI 挑选】——本 Skill 的核心

拿到清单后，**逐条阅读标题**，按下面的**类型定义清单**判断每条资源属于哪类，挑出用户要的那一类的前 N 个。

### 3.1 预设资源类型清单

| 类型 | 识别特征（标题信号） | 典型示例 |
|---|---|---|
| **自我提升/成长** | 书/册/套装、认知/思维/习惯/情商/心理、方法论、励志、个人成长 | 掌控习惯、认知觉醒、思维模型30种 |
| **学习/考试资料** | 学习法、考研/考公/考证、真题、笔记、教辅、课本、网课 | 脑科学学习法、学习的逻辑、985逆袭学习方法 |
| **编程/技术教程** | 前端/后端/Python/Java、全栈、项目实战、源码、架构、313集/完结 | web前端全栈高薪就业课 |
| **软件/工具** | 安卓软件、破解版/修改版、安装包、APK、效率工具、模板 | 哔哩哔哩国际版 |
| **技能教程** | 剪辑/摄影/设计/绘画/Excel/PPT/办公、教程、实战案例 | 暖通工程施工图识图 |
| **考试升学** | 中小学、高考、中考、作文、数学、英语、年级、提分 | 1-6年级作文动画课 |
| **有声/鉴赏** | 名曲/鉴赏、有声书、讲座、通史、朗读 | 中国十大古典名曲鉴赏 |
| **理财/职场** | 理财、投资、副业、职场、管理、创业 | 创业家思维 |
| **短剧/影视（默认排除）** | 短剧、动漫、剧集、综艺、电影、第N季、更新目录 | #短剧🗄、#动漫🗄 |
| **小说（默认排除）** | 第N季、重生/穿越/赘婿/战神/总裁/王妃、集数结尾 | 某某逆袭记(80集) |

### 3.2 挑选规则

1. **优先排除**噪声：`#短剧`/`#动漫`/`#综艺` 前缀、`更新目录`、`第N季`、`(N集)` 结尾的网文短剧。
2. **按用户要求的类型**从清单中挑；**同一本书的不同版本只取 1 个**（如"认知觉醒(套装全8册)"出现多次只选 1 条）。
3. **宁缺毋滥**：全量池里干货通常只占 5%~15%。若挑不满 N 个，如实告知用户实际能挑出的数量，**不要用短剧凑数**。
4. **记录序号**：挑完后记下每条对应的 `[序号]` 和关键标题片段，用于第 4 步锁定。

## 4. 用 `--include` 锁定挑选结果并推送

把上一步选中的资源，用**标题关键词**（每条取一个唯一片段）作为 `--include` 参数：

```powershell
# RunCommand — blocking=true，等待完整输出（转存较慢，8 个约需 3~15 分钟）
python main.py quark --count 8 --include 掌控习惯 --include 微习惯 --include 助理建筑师 --include 脑科学学习法 --include 30种模型 --include 学习的逻辑 --include web前端全栈 --include 哔哩哔哩
```

### 参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| platform | — | `quark` / `baidu` / `all` |
| --count | 6 | 转存数量 |
| --include | 无 | **必须用**：填入挑选出的资源标题片段（可重复指定） |
| --exclude | `可搜索` | 通常不需要；空关键词结果已足够干净 |
| --kw | **留空** | ⚠️ 本流程固定留空，不要传主题词 |
| --force | false | 跳过本地缓存（需要最新结果时可加） |
| --preview | false | 只预览不转存 |

> **注意**：`--include` 是「标题包含任一关键词即保留」，所以关键词要**足够独特**避免误带其他资源。

### 若挑选数量与实际不符

- 用户要 N 个，但池里只有 M 个（M < N）→ 直接推 M 个，并告知"全量池里符合该类型的只有 M 个"。
- 推送中部分源失效（`获取 stoken 失败：分享者用户封禁`）→ **回第 2 步重新拉取全量清单，再挑 M 个补足**（保持流程一致，不要改用主题关键词）。

## 5. 结果判读

### 成功标志
- 看到 `转存成功 [N/M]` 日志
- 看到 `引流清理完成：检查 X 个，删除 Y 个`
- 看到 `分享成功 [N]: xxx - https://pan.quark.cn/s/xxxx`
- 最后输出 `全部任务完成`

### 失败处理
| 现象 | 含义 | 处理 |
|---|---|---|
| `WinError 10061` | PanSou 没在跑 | 回到第 1 节启动 |
| `获取 stoken 失败（分享者用户封禁）` | 源分享被封 | 正常损耗，重新挑选补足 |
| `转存失败 -8` | 目录已有同名 | 正常，跳过 |
| `转存失败 -6`（百度） | Cookie 失效 | 提示用户重新抓 Cookie |

## 7. 注意事项

- **PanSou 是长驻服务**，启动后不要关闭那个终端窗口，下次推送直接复用
- **每次都用空关键词**：本流程固定 `--kw` 留空，由 AI 从全量池里挑选，不依赖主题词搜索
- **去重**：已推送过的资源会自动过滤（按标题匹配），不会重复转存
- **引流清理在前，上传在后**：先删掉别人的，再上传自己的 99999.pdf，确保自己的 PDF 不被误删
- **Cookie 有效期**：夸克 Cookie 可能 1~2 周过期，过期后转存/分享报错，提示用户重新抓
