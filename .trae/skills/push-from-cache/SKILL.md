# Push From Cache - 从盘搜缓存清单挑资料并推送

用户说"从缓存里挑 N 个 XX 类的"、"从这个清单里选 XX 方面的资料推给我"时，**立即使用本 Skill**。

> **与另两个 skill 的分工**：
> | Skill | 选择依据 | 典型场景 |
> |---|---|---|
> | `push-resource` | AI 按**预设类型表**挑 | "推 6 个学习类"（类型在预设清单内） |
> | `push-random` | 程序**随机抽取** | "随便挑几个" |
> | **`push-from-cache`（本 skill）** | AI 按**用户当场临时指定的领域**判断 | "从缓存里选小学语文英语类的推送" |
>
> **本 skill 的独特点**：① 领域标准是**对话里临时给的**，不依赖预设类型表；② 用 `--text` 走**链接替换+文本推送**通道（产出"文字+新链接"的成品文本），而不是只发裸链接。

---

## 核心流程（四步）

```
① 拿缓存清单（含 url 的 JSON）
        ↓
② 【AI 判断】按用户当场说的领域，逐条筛出符合的条目
        ↓
③ 逐条转存：原文链接 → 我自己的分享链接（--text 替换通道）
        ↓
④ 组装「文字 + 替换后链接」→ 推送企业微信
```

## 2. 拿缓存清单（含 url 的 JSON）

```bash
python3 tools/list_resources.py --json /tmp/cache_pool.json
```

- 不传 `--refresh` = 用本地缓存（12h 内），**快**；要最新池子加 `--refresh`（较慢）
- 产物 `/tmp/cache_pool.json` 结构：
  ```json
  [
    {"index": 1, "note": "web前端全栈高薪就业课-大神coderwhy出品【313集完结】", "url": "https://pan.quark.cn/s/xxxx"},
    ...
  ]
  ```

同时会打印可读清单：

```
# 空关键词全量结果：236 条（platform=quark）
[1] #短剧🗄 2026年10月8日 短剧更新目录1
[2] web前端全栈高薪就业课-大神coderwhy出品【313集完结】
...
```

> **若已有历史缓存清单文件**（如用户提供的 `/tmp/full3.txt` 等只有标题、没有 url 的版本），**不能直接用** —— 必须用 `--json` 重新导出，因为后续转存需要 url。只有标题的清单只能用于"看"，无法替换链接。

## 3. 【AI 判断】按用户当场指定的领域筛选

### 3.1 领域标准来自对话

**不要预设类型表**。用**用户当前这句话里给的领域描述**作为唯一标准。例如：

| 用户说 | AI 的判断标准 |
|---|---|
| "选小学语文英语类的" | 标题含 小学/一年级~六年级、语文、英语、阅读理解、作文、听力、字词、拼音 等**小学语文/英语学习资料**；排除中学、其他学科、影视短剧 |
| "选编程技术类的" | 标题含 编程/前端/后端/Python/Java/全栈/项目实战/源码 等 |
| "选考公考研资料" | 标题含 考公/公考/省考/国考/事业单位/考研/真题/押题/专业课 等 |
| "选 AI 相关的教程" | 标题含 AI/人工智能/大模型/AIGC/提示词/Agent 等**教程类** |

### 3.2 筛选规则

1. **正面匹配领域**：标题必须能明确判断属于用户要的领域，**拿不准的一律不要**（宁缺毋滥）。
2. **排除噪声**：`#短剧`/`#动漫`/`#综艺` 前缀、`更新目录`、`(N集)` 网文短剧，除非用户明确要这些。
3. **去重**：同一资源的不同版本/重复条目只留 1 条。
4. **记录**：挑出的每条记下 `index` / `note` / `url`，用于第 4 步。

### 3.3 数量策略

- 用户说"挑 N 个" → 挑到 N 个为止
- 用户没给数量 → **全部符合的都挑出来**（上限建议 ≤15，避免推送过长）
- **全量池里符合特定领域的通常只占 5%~20%**。若挑不满用户要的数量，**如实告知实际数量，不要用无关资源凑数**

## 4. 逐条转存替换链接

### 方式 A：用 `--text-file` 批量替换（**推荐**，一条命令搞定）

把挑出的资源拼成一段文本（每行"标题：原链接"），存入文件后用项目的文本替换通道：

```bash
cat > /tmp/pick_input.txt <<'EOF'
小学语文阅读理解常考题型和答题技巧：https://pan.quark.cn/s/3a93d309afab
2027版《万唯大小卷》9全英语（人教版）：https://pan.quark.cn/s/f1e878407836
1-6年级《全新英语听力》（基础+提高版）：https://pan.quark.cn/s/748573a93c98
EOF

python3 main.py quark --text-file /tmp/pick_input.txt --output /tmp/pick_output.txt --save-history
```

- 程序会自动识别文本里的**夸克链接** → 转存 → 生成新分享链接 → **原样替换到文本对应位置**
- 输出：`/tmp/pick_output.txt`（**文字+替换后链接**，正是要推送的成品）
- 非夸克链接（官网/论坛等）保持原样不动

### 方式 B：用 `--include` 精确锁定推送

若要复用常规推送通道（也发企业微信）：

```bash
python3 main.py quark --count 6 --include "<标题片段1>" --include "<标题片段2>"
```

> 本 skill 默认走**方式 A**，因为用户要的是"**文字加链接**"这种文案形态。

### 执行注意

- **必须后台跑**：每个资源约 10~60 秒，多个资源需数分钟，避免超时
- **`--kw` 留空**（不要传主题词；本流程用清单里的 url 直接转存，不依赖搜索）
- 转存有正常损耗：部分源已封（`获取 stoken 失败`）、部分转存为空（`转存结果为空`），**属正常现象**

## 5. 组装文本并推送企业微信

### 5.1 检查替换结果

```bash
cat /tmp/pick_output.txt
```

确认每行都是**新链接**（`pan.quark.cn/s/` 后跟新 ID），并核对成功/失败数量。

### 5.2 推送

`--text-file` 通道**默认已推送企业微信**（内部调用 `WECHAT_WEBHOOK_URL`）。

若需**单独重发**或**自定义文案**（如加标题、加分类小标题），用 `--text` 直接推送：

```bash
python3 main.py quark --text "【小学语文英语资料合集】

📚 小学语文阅读理解答题技巧
https://pan.quark.cn/s/<新链接>

📚 2027版《万唯大小卷》9全英语
https://pan.quark.cn/s/<新链接>" --push-wechat
```

### 5.3 交付成品

把最终文本**同时**：
- 写入 `/workspace/<描述性文件名>.txt`（供用户复制）
- 用 `present_files` 呈现

## 6. 结果判读

### 成功标志
```
夸克转存+分享成功: <资源名>
===== 处理完成: N/N 成功 =====
企业微信通知发送成功
替换完成: 成功 N/N
已写入: /tmp/pick_output.txt
```

### 失败处理

| 现象 | 含义 | 处理 |
|---|---|---|
| `本地过滤：X → 0 条` | `--include` 关键词在池里不存在 | 用 `--preview` 看池子实际标题，改关键词 |
| `获取 stoken 失败（分享者用户封禁）` | 源被封 | 正常损耗，从清单换一条补 |
| `转存结果为空` | 目录已有同名/分享者限制 | 正常损耗，换一条 |
| `分享失败: 'data'` | 转存内容为空（常因**主文件被引流清理误删**） | 换一条；频繁出现需修引流规则 |
| `企业微信通知发送失败` | Webhook 失效 | 提示用户检查 `.env` 的 `WECHAT_WEBHOOK_URL` |

## 8. 注意事项

- **领域标准每次从对话读**：不要套用固定类型表；用户说"小学语文英语类"就按这个筛，下次说"运营副业"就按那个筛
- **清单必须含 url**：只有标题的 txt 无法替换链接，务必先用 `tools/list_resources.py --json` 导出
- **宁缺毋滥**：拿不准属不属于目标领域的一律不选，绝不能拿短剧/影视凑数
- **`--text-file` 是最优路径**：它天然产出"文字+替换后链接"的成品，且自动推企业微信，与本需求完全吻合
- **去重自动生效**：已推送过的资源会按标题指纹过滤，不会重复转存
- **PanSou 长驻**：启动后保持运行，后续复用
